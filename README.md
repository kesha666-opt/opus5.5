# Nova Code Bridge

Упрощённый локальный шлюз NVIDIA NIM для Claude Code на macOS. После установки пользователь видит только поле API‑ключа NVIDIA, кнопку сохранения/проверки и фактический статус подключения.

## Установка

Приватная публикация ещё не выполнена. После публикации установщик скачивает
исходники через авторизованный GitHub CLI. Загрузка без авторизации запрещена.
Окончательная команда установки с нуля будет проверена после публикации.

После зелёного статуса в панели откройте терминал и запустите:

```sh
fcc-claude
```

Панель: <http://127.0.0.1:8182/admin>

Настройки хранятся отдельно в `~/.nova-code/.env`. Существующая установка FCC в `~/.fcc` и её порт `8082` не изменяются. При повторной установке текущий файл настроек предварительно копируется в `~/.nova-code/backups/`.

## Что настроено заранее

- Провайдер: NVIDIA NIM.
- Модель: `nvidia/nemotron-3-super-120b-a12b` через маршрут `nvidia_nim`.
- Локальный порт: `8182`.
- Команды: `fcc-server` и `fcc-claude`.

Модель NVIDIA не является Claude Opus. Claude Code здесь выступает клиентским интерфейсом, а ответы генерирует выбранная модель NVIDIA. Доступность и лимиты определяет NVIDIA.

В JSON-отчёте Claude Code поле `modelUsage` может по-прежнему называться
`claude-opus-*` и содержать расчётную стоимость Anthropic. Это клиентская
оценка совместимого интерфейса, а не подтверждение запроса или списания у
Anthropic. Фактический маршрут задаётся Nova Code и в этой сборке ведёт в
NVIDIA NIM.

## Удаление

```sh
uv tool uninstall nova-code-bridge
```

Эта команда удаляет пакет; настройки остаются в ~/.nova-code. Имена
fcc-server и fcc-claude совпадают с исходным FCC: установщик останавливается
при обнаружении другой установки с этими командами.

## Проверки без секретов

```sh
uv run pytest tests/nova
```

Реальная проверка NVIDIA выполняется только после того, как пользователь сам введёт ключ в локальной панели. Ключ маскируется API конфигурации и не должен попадать в Git, командную строку или журналы.
